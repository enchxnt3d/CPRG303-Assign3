# Employee Management App (Expo React Native)

## Overview

This project is a React Native (Expo) application developed as part of CPRG303 Assignment 4.

The application allows authenticated users to manage employee information using a backend service. It includes user authentication, protected navigation, form validation, and backend data persistence.

---

## Backend

- Firebase Authentication
- Cloud Firestore Database

---

## Features

### Authentication

- User Sign Up
- User Sign In
- User Sign Out
- Protected Routes
- Session Persistence

### Employee Management

- Create Employee Record
- Read Employee Records
- View Employee List

### Form Validation

- Formik
- Yup Validation

### User Experience

- Loading Indicators
- Network Error Handling
- Empty State Handling
- Consistent UI Across Screens

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Start the project

```bash
npx expo start
```

Run on

- Android Emulator
- iOS Simulator
- Physical Device using Expo Go
